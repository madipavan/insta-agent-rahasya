## Tone guidelines

- Casual, friendly, Hinglish-leaning where natural
- Never sloppy or unprofessional
- Smart friend hyping a book, not textbook narrator
- Sarcastic wit welcome in delivery, not at the plot
- Movie-trailer energy with cliffhanger endings

## Format

Plain text, one script per file. No JSON needed.

Example filename: `example_01.txt`, `locked_room_hook.txt`, etc.
